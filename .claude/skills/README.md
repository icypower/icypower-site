Trimmed on purpose: the `evals/` folders, and references that don't fit a
Hebrew-only local service business (international SEO, LinkedIn, YouTube,
OKF, SaaS agent-defaults, citation-tracking vendor material, platform
migration). `ai-seo` mentions some of them; it is written to carry on without
them. One local fix: two broken links in `seo-audit/references/local-seo.md`
now point at the real `local-seo-*` file names.

House rules that override anything in these skills:
- Business facts come from `.claude/product-marketing.md`, `seo/README.md` and
  CLAUDE.md. Never invent prices, reviews, ratings, clients or addresses.
- Don't run `npx`/third-party audit tools or sign up for services mentioned in
  the skills; free, local checks only (Playwright is preinstalled).
- The skills' "ask the user" steps are skipped when running unattended: use
  the product-marketing file instead.
