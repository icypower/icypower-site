# SEO - how it works and what the weekly agent does

Free-only SEO for https://icypower.pages.dev (the only public address).
**Goal: leads (WhatsApp / phone / contact form) for corporate team-building
events and private groups**, anywhere in Israel - mostly the centre, also the
north and south (not as far as Eilat).

## What's in place
| Piece | File | Notes |
|---|---|---|
| Titles, descriptions, canonical, Open Graph, Twitter, JSON-LD | `seo/pages.json` → `python3 seo/inject_head.py` | Never hand-edit the `SEO:START`…`SEO:END` block in an HTML page; edit `pages.json` and rerun. |
| Structured data | same | LocalBusiness + EntertainmentBusiness (service area = all Israel regions/cities), Service per offering page, BreadcrumbList, FAQPage on the home page, WebSite. |
| Sitemap | `sitemap.xml` | Generated by the same script (lastmod = last git commit of the page). |
| robots.txt | `robots.txt` | All crawlers + AI bots allowed; points to the sitemap. |
| AI answer engines | `llms.txt` | Plain-English summary for ChatGPT / Claude / Perplexity. Keep in sync when services change. |
| IndexNow (Bing, Yandex → also ChatGPT search / Copilot) | `<key>.txt` at the root + `.github/workflows/indexnow.yml` | Pings all sitemap URLs after every push to `main`. |
| Share images | `assets/img/og/*.jpg` | 1200×630. |
| Hidden pages | `_headers` + meta robots | proposals, invites, divorced-and-happy, archive, waiver, booking-success are `noindex` and not in the sitemap. |

| SEO skills | `.claude/skills/{seo-audit,ai-seo,schema,site-architecture}` | Reviewed copies from marketingskills (MIT); business facts for them in `.claude/product-marketing.md`. See `.claude/skills/README.md`. |

Notes from the skills worth keeping in mind:
- Google stopped showing FAQ rich results in May 2026. The FAQPage markup
  stays because AI engines (Perplexity, ChatGPT) still read it, but don't
  expect expandable FAQs in Google.
- Google's LocalBusiness rich result needs a street address; we don't
  publish one on purpose, so the markup is for understanding, not a rich result.
- Claude's web search uses Brave Search, ChatGPT and Copilot use Bing. Bing is
  covered by IndexNow; check search.brave.com for the brand now and then.

URLs: Cloudflare Pages serves `/business.html` at `/business` (308 redirect),
so canonical URLs and the sitemap use the extension-less form.

## Adding a new public page
1. Create the HTML page (copy an existing one's nav/footer).
2. Add an entry to `seo/pages.json` (`file`, `path` without `.html`, `crumb`,
   `title` ≤ 60 chars, `description` 120–160 chars, `image`, `imageAlt`,
   optional `service`).
3. `python3 seo/inject_head.py`, link the page from the footer and at least
   one related page, add it to `llms.txt`.

## Content backlog for the weekly agent (one item per run, best first)
1. `/business`: add an FAQ block for HR buyers (how long, how many people, what
   space is needed, indoor/outdoor, winter, insurance/safety, what's included,
   how to book) + matching `faq` in `pages.json`.
2. A guide page: "רעיונות ליום גיבוש לעובדים" - genuinely useful list, with the
   ice-bath workshop as one option and a CTA.
3. A guide page: "אמבטיות קרח - כל מה שצריך לדעת לפני הפעם הראשונה" (safety,
   benefits with honest wording, who shouldn't do it).
4. A guide page: "רעיונות למסיבת רווקות שונה".
5. A "where we come to" (אזורי שירות) page: one real page describing how
   events work in the centre / Sharon / Jerusalem / north / south, travel
   notes, past venue types. One page, not one page per city.
6. `/private-groups` and `/events`: FAQ blocks.
7. Short case-study blurbs (with permission-safe wording) using the client
   logos already on the home page (Philips, IDF, Vamos, החלוץ...).
8. Internal links: each guide links to `/business` or `/private-groups` and
   `/contact`; the service pages link to the relevant guide.

## Rules for content
- Hebrew, natural, the brand voice: relaxation + fun + connection + practical
  stress tools + a touch of luxury. No em dashes, no AI buzzwords.
- No invented facts: no fake reviews, prices, client names, ratings,
  addresses, certifications or medical claims. Use what's already on the
  site or in this repo's CLAUDE.md. If a fact is missing, write around it.
- No `aggregateRating`/`Review` schema unless real reviews exist on the page.
- No doorway pages (near-duplicate pages per city), no keyword stuffing,
  no hidden text.

## Things only a human can do (free, optional, ~10 minutes each)
These need logging in to a Google/Microsoft account, so the agent can't do them:
- **Google Search Console** → add property `https://icypower.pages.dev`
  (URL-prefix), verify with the HTML-tag method (send the tag to Claude and it
  goes into `inject_head.py`), then submit `sitemap.xml`.
- **Bing Webmaster Tools** → "Import from Google Search Console" (feeds Bing,
  ChatGPT search and Copilot).
- **Google Business Profile** as a *service-area business* (hide the address,
  service areas: מחוז המרכז, תל אביב, השרון, ירושלים, חיפה, הצפון, הדרום),
  category "Wellness program" / "Team building", link to the site, ask happy
  clients for Google reviews. This is the single biggest free lead source
  for local searches.
- Free listings/backlinks: Instagram bio link, Facebook page, Easy.co.il,
  B144, Zap, wedding/bachelorette idea blogs, and any partner venue's site.
